# Machine Learning Projects

A collection of practical Machine Learning projects built with Python and Scikit Learn.

This repository documents my hands on practice with Machine Learning, from data preprocessing and model building to evaluation and prediction.

## Projects

### Breast Cancer Classification

A classification project using Logistic Regression and Decision Tree with Scikit Learn Pipeline.

**Concepts:** Classification, preprocessing, feature scaling, Pipeline, model evaluation

### Iris Classification

A classification project using Logistic Regression to predict iris flower species.

**Concepts:** Classification, StandardScaler, Pipeline, model evaluation

### California Housing Regression

A regression project using Linear Regression to predict housing prices.

**Concepts:** Regression, preprocessing, Pipeline, prediction and evaluation

### Dataset Model

Practice with preparing datasets, training Machine Learning models and evaluating their performance.
